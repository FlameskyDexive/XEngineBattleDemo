# com.xengine.zonezero

Zenless-Zone-Zero-style anime combat demo for XEngine: YSA Toon shader re-implementation,
tag-team combat (4-hit combo, dodge, big-skill camera cuts), skill VFX. Depends on
`com.xengine.unityimporter` (+ inputsystem/cinemachine/probuilder as they land). See
`Documentation~/index.md` and the plan at
`docs/superpowers/specs/2026-08-21-zonezero-combat-demo.md`.
